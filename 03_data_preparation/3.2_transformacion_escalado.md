# Transformación Matemática y Prevención de Leakage

## 1. Codificación de Variables
- **Mapeo Binario:** Las variables de Sí/No (1/2) se transformaron a 1/0.
- **Variables Categóricas (Etnia):** Se aplicó `pd.get_dummies(drop_first=True)`. Se eliminó la primera categoría para evitar la "Trampa de las Dummies" (multicolinealidad perfecta) que confunde a los modelos lineales y de distancia.

## 2. Alineación Crítica de Columnas
Si una categoría de etnia (ej. Gitano) no aparece en el Test Set, `get_dummies` genera una dimensión distinta. 
**Acción:** Se utilizó `df_train_proc.align(df_test_proc, join='left', axis=1, fill_value=0)` para garantizar que Train y Test tengan exactamente las mismas 11 columnas.

## 3. Escalado Z-Score (Anti-Leakage)
K-Means calcula distancias euclidianas. Si no se escala, variables como Edad (0-104) aplastarían variables binarias (0-1).
**Acción:** Se utilizó `StandardScaler`. 
- **Regla de Oro:** El `fit()` se ejecutó **exclusivamente** con `X_train`. El `transform()` se aplicó a Train y Test. Esto simula la realidad: el modelo no puede conocer la media del futuro (Test Set). Resultado: Media Train = 0, Desviación Train = 1.
