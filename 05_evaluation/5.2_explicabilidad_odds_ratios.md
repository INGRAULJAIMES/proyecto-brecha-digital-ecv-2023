# Explicabilidad de la Inclusión Financiera (Odds Ratios)

## 1. La Regresión Logística
Para entender qué variables determinan realmente el uso de banca digital (P1083S5), se entrenó un modelo Logit (con Statsmodels). Se excluyó la variable "Tener Celular" para evitar el fenómeno de **Separación Perfecta** (si no tienes celular, es matemáticamente imposible que uses banca, lo que rompería el modelo).

## 2. Los Hallazgos Estadísticos (Odds Ratios con IC 95%)
- **Smartphone (OR = 64.10):** Multiplica por 64 las probabilidades (odds) de usar banca digital. Es la variable más determinante del estudio. El acceso al hardware es el cuello de botella real de la inclusión financiera.
- **Mujer (OR = 0.8514):** A igual estrato, edad, etnia y tenencia de smartphone, el hecho de ser mujer reduce las probabilidades de usar banca en un 15% (1 - 0.8514). Es una brecha estructural de género.
- **Estrato (OR = 1.21):** El estrato aporta un mísero +21% a las probabilidades de inclusión. Es secundario comparado con el hardware.

## 3. El Pseudo-R² de McFadden (0.166)
El modelo tiene un Pseudo-R² de 0.166. Esto significa que las variables observadas (Estrato, Edad, Sexo, Etnia, Smartphone) explican solo el **16.6%** de la probabilidad de usar banca digital. 
**Conclusión:** El **83.4%** restante depende de factores no observados (confianza en el sistema financiero, educación digital, oferta bancaria local, hábitos). Esto valida rotundamente el uso de **clustering**: el algoritmo capturó esa varianza no observada que la regresión tradicional no puede medir.
